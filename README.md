# Exploratory Data Analysis (EDA) Using NumPy and Pandas

## Overview
This project demonstrates Exploratory Data Analysis (EDA) on the Titanic dataset using NumPy and Pandas.

## Libraries Used
- NumPy
- Pandas
- Matplotlib
- Seaborn

## Dataset
Titanic Dataset (CSV)

## Steps
1. Import libraries
2. Upload dataset
3. Load CSV
4. Check data
5. Statistical analysis
6. Missing values analysis
7. Correlation heatmap
8. Visualization
9. Conclusion

## Conclusion
EDA completed successfully using NumPy and Pandas.
